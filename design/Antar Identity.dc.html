01

Wordmark

The mark is the word, set in Tiro Devanagari Hindi and not redrawn. A hand-drawn logotype would be the one element on the site that cites nothing. What carries the meaning instead is the measured gap: in the lockup, the two scripts are held apart by a dimension line with end ticks — the distance made into a typographic device rather than an illustration.

Favicon — अं

अं survives 16px because it is two marks with air between them: one closed counter and one dot. Reversed out of plum, the dot stays separate at every size tested below. Set in Tiro at 78% of the tile height, optically centred — the anusvara pushes the visual centre down, so the glyph sits 1px above geometric centre.

03

Palette

Colour is used for exactly one thing: the gap. Nothing else on the site is coloured — status, category, verification state and roadmap stage are carried by weight, outline, hatch and rule instead. That is not restraint for its own sake. A palette with one accent has no slot for a good/bad pair, so the page cannot code a verdict even by accident, and the saffron-and-green problem never arises because there is no second hue to reach for.

Plum sits outside Indian party colour — not saffron, not green, not the blues of AAP and BSP, not the reds of the left. The ground moves from cream to a cool grey: cream reads as a literary blog, cool grey reads as a document. At 6.6:1 on paper the accent is legible as text, not only as a fill, which matters because the remaining figure is set in it.

Devanagari is not the same numbers with a different name
  • Body leading 1.78 in Hindi against 1.6 in English. Matras sit above the shirorekha and conjuncts below the baseline; 1.6 collides them.
  • Headline leading 1.34 against 1.14.
  • No uppercase transform and no letterspacing on Devanagari, ever — tracking breaks the shirorekha. Hindi micro-labels are set at 13px instead of 11px shouted.
  • Hindi body runs one step larger where the two sit side by side, so the two columns have equal optical weight.
  • Measure 64ch in Latin, 52ch in Devanagari: the same character count is a longer line.
  • Each page loads only the script it needs, as today. Tiro Devanagari Hindi carries both, so the English page still gets a co-designed Latin.
